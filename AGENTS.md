# VDL-Verified-Development-Loop

Invoke `$vdl-verified-development-loop` from `skills/vdl-verified-development-loop/` only when the user explicitly requests it or asks to run a software change through interview, Spec, Plan, human approval, TDD, verification, and review. Ordinary edits, bug fixes, UI tweaks, questions, and maintenance of the workflow or dashboard do not start this process. When invoked, read its `SKILL.md` and relevant references, pass the bundled `agents/` roles to the current host's native subagents, and use its scripts for state and evidence.
